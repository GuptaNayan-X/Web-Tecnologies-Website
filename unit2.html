HTML

Document structure, elements, attributes, formatting, and HTML5.

What Is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes a page's structure through nested elements that define layout blocks; the browser interprets these tags to render content — it never displays the raw tags themselves.

html
<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    <h1>My First Heading</h1>
    <p>My first paragraph.</p>
  </body>
</html>

<!DOCTYPE html> declares an HTML5 document · <html> is the root element · <head> holds metadata · <title> sets the browser tab text · <body> contains everything visible.

Tip: press Ctrl+U (Cmd+Option+U on Mac) to view a page's raw source, or right-click → Inspect to explore live elements and styles in DevTools.

A Brief History of HTML

1989 Tim Berners-Lee invents the Web → 1991 he writes HTML → 1993 Dave Raggett drafts HTML → 1995 HTML 2.0 → 1997 HTML 3.2 (W3C) → 1999 HTML 4.01 → 2000 XHTML 1.0 → 2008–2014 WHATWG drafts culminate in the HTML5 W3C Recommendation (2014) → 2016–2017 HTML 5.1 / 5.2.

Elements, Tags & Nesting

An element = start tag + content + end tag, e.g. <p>My first paragraph.</p>. Empty elements like <br> have no content and no closing tag. Elements nest inside one another, and closing tags must mirror the opening order: <html><body>…</body></html>.

Never skip a closing tag — browsers may auto-correct malformed markup, but relying on that causes unpredictable rendering, style leakage and accessibility bugs. HTML tags are case-insensitive (<P> = <p>), but W3C recommends — and XHTML requires — lowercase.

HTML Attributes

Attributes live only in the start tag, as name="value" pairs, and modify an element's default behaviour.

AttributeUsed onPurpose
href<a>Link destination
src<img>Resource path — absolute (external) or relative (local, more resilient)
width / height<img>Reserves layout space, prevents shift while loading
alt<img>Fallback text for accessibility / broken images
styleany elementInline CSS, e.g. style="background-color:powderblue;"
lang<html>Declares page language, e.g. lang="en-US"
titleany elementHover tooltip / advisory text

Always quote attribute values (mandatory once a value contains a space) and prefer lowercase attribute names. If a value itself contains quotes, alternate styles: title='John "Ace" Smith' or title="John 'Ace' Smith".

Headings, Paragraphs & Whitespace

<h1>–<h6> define six levels of heading importance — use only one <h1> per page, and never use headings just to make text big or bold (search engines use them to index structure; resize with style="font-size:60px;" instead). <p> defines a block-level paragraph; browsers add margin before and after automatically.

Extra spaces and line breaks in your source code collapse to a single space when rendered (the "poem problem") — use <pre> to preserve exact whitespace and line breaks in a monospace font. <hr> inserts a thematic break; <br> forces a line break without starting a new paragraph.

HTML Colors

Colors can use 140+ named keywords or three numeric models:

  • RGB — rgb(red, green, blue), each 0–255, e.g. rgb(255,99,71); RGBA adds an alpha (0–1) for opacity.
  • HEX — #RRGGBB, two hex digits per channel, e.g. #ff6347.
  • HSL — hsl(hue, saturation, lightness): hue 0–360° (0=red, 120=green, 240=blue), saturation 0–100% (0%=gray → 100%=full color), lightness 0–100% (0%=black → 100%=white). HSLA adds an alpha channel.

Try it — live HSL mixer:

hsl(210,70%,55%)

Hyperlinks

html
<a href="https://www.itmbu.ac.in" target="_blank">Visit ITMBU</a>
<a href="https://example.com"><img src="logo.png" alt="Logo"></a>
<a href="mailto:info@itmbu.ac.in">Email us</a>

Images and buttons can be wrapped in an <a> too, and mailto: links open the user's email client. The target attribute controls where the link opens: _self (default, same tab), _blank (new tab), _parent, _top.

Absolute URL — full address to an external resource. Relative URL — a path within the same site (e.g. images/pic.jpg); preferred, since it survives a domain change.

Lists

<ul>
Unordered (bulleted) list of <li> items; type can be disc, circle or square.
<ol>
Ordered (numbered) list of <li> items; type can be 1, A, a, I or i.
<dl>
Description list pairing <dt> (term) with <dd> (description).

Tables

<table> defines the table, <tr> a row, <td> a standard cell, <th> a bold, centered header cell.

html
<table>
  <tr><th>Name</th><th>Marks</th></tr>
  <tr><td>Asha</td><td>92</td></tr>
</table>

Images

html
<img src="img_girl.jpg" alt="Girl with a jacket" width="500" height="600">

<img> is an empty (self-closing) element. src can be absolute or relative; alt is essential for accessibility and shows if the image fails to load; width/height prevent layout shift while loading. Common formats: JPEG, PNG, GIF, SVG, WebP.

Forms & Input

html
<form action="/action_page.php">
  <label for="fname">First name:</label>
  <input type="text" id="fname" name="fname">
  <input type="submit" value="Submit">
</form>

<form> wraps and coordinates all input controls, typically posting to a server via action. <input> is the core control — its behaviour depends on type:

TypeBehaviour
textSingle-line text field
radioPick one option from a group sharing the same name
checkboxPick any number — selections are independent
submitSends the form data to the server
emailHTML5 — validates an @ symbol
dateHTML5 — native calendar picker
colorHTML5 — native color picker
rangeHTML5 — draggable slider

<label for="id"> ties descriptive text to a control by matching its id — screen readers read it aloud, and clicking the label focuses/toggles the control.

HTML5: Semantics, Media & APIs

Semantic elements replace generic <div id="header"> with self-describing tags — <header>, <nav>, <main>, <article>, <section>, <aside>, <footer> — improving SEO and screen-reader navigation.

html
<video width="600" controls>
  <source src="lecture.mp4" type="video/mp4">
</video>

<audio controls>
  <source src="podcast.mp3" type="audio/mpeg">
</audio>

Native <video> / <audio> need no plugins. The Drag & Drop API: add draggable="true" to make any element draggable, then handle JS events like ondragstart and ondragover.

Meta Tags & XHTML

Meta tags live inside <head>, invisible to visitors but critical for machines:

TagPurpose
<meta charset="UTF-8">Character encoding
<meta name="viewport" content="width=device-width, initial-scale=1">Responsive scaling on mobile
<meta name="description" content="...">Summary shown in search results

XHTML is the strict, XML-based version of HTML: tags must be lowercase, every element must be properly closed — including empty ones, e.g. <br /> — and nesting must be perfectly ordered. Unlike HTML5, it won't forgive small mistakes.
