Cascading Style Sheets (CSS)

Detailed study notes aligned with the supplied Unit 3 study guide. Review the explanations, tables, examples and recap before practising the code.

01. Why CSS Is Needed

HTML describes the meaning and structure of web content. CSS controls how that content is presented: its colors, typography, spacing, borders and layout. Keeping structure and presentation separate makes pages easier to maintain and more consistent.

  • Separate content and design: keep headings, paragraphs, lists and forms in HTML and place visual rules in CSS.
  • Reuse one design: one external stylesheet can style many pages; changing a rule can update the site consistently.
  • Adapt to screens: flexible layouts and media queries help content work on phones, tablets and desktop displays.
  • Reduce repeated work: reusable selectors avoid copying presentation declarations into every HTML document. Browsers can also cache external stylesheets.

Same content, different presentation

The words in a page can remain the same while CSS changes typography, color, border, spacing and depth. This is the central purpose of CSS: presentation changes without rewriting the content.

HTML
<h2>Course update</h2>
<p>CSS lecture begins at 10:00 AM.</p>
CSS
h2 {
  color: #174f78;
  border-bottom: 2px solid #174f78;
  padding-bottom: 0.5rem;
}
p {
  color: #344054;
  line-height: 1.6;
  background-color: #f1f6fa;
  padding: 1rem;
}

Three Ways to Add CSS

MethodWhere it goesBest suited for
External stylesheetA separate .css file linked from the HTML <head>Shared site-wide styles and maintainable projects.
Internal stylesheetA <style> element in the document <head>Styles used by one standalone page.
Inline styleThe element's style attributeA one-off demonstration; avoid repeated styling this way.
HTML
<!-- External: reusable across multiple pages -->
<link rel="stylesheet" href="styles.css">

<!-- Internal: rules for this document -->
<style>
  h1 { color: #174f78; }
</style>

<!-- Inline: a single element -->
<p style="color: #31765e;">Styled text</p>

Study tip: external CSS is generally the best choice for a multi-page website because it supports reuse and easier maintenance.

02. CSS Syntax and Selectors

A CSS rule consists of a selector followed by a declaration block. Each declaration pairs a property with a value; declarations are normally separated by semicolons and enclosed in braces.

CSS
p.notice {
  color: #153c5b;                 /* property: value */
  background-color: #e8f2f8;
  border-left: 5px solid #2196f3;
  padding: 14px;
}

In this rule, p.notice is the selector. The properties are color, background-color, border-left and padding; the values appear after each colon.

Common selectors

SelectorWhat it matchesExample
Element: pEvery paragraph element.p { line-height: 1.6; }
Class: .noticeEvery element whose class includes notice..notice { padding: 1rem; }
ID: #main-titleThe element with that ID, intended to be unique.#main-title { color: navy; }
Universal: *All elements.* { box-sizing: border-box; }
Grouping: h1, h2Both heading types.h1, h2 { color: navy; }
Descendant: nav aLinks anywhere inside a navigation element.nav a { text-decoration: none; }
Child: ul > liList items that are direct children of a list.ul > li { margin-block: .5rem; }
Pseudo-class: a:hoverAn element in a state, such as when the pointer is over a link.a:hover { color: green; }
Pseudo-element: p::first-lineA particular part of an element.p::first-line { font-weight: bold; }
Attribute: input[type="email"]Inputs with a matching attribute.input[type="email"] { border-color: teal; }

CSS Values, Units, Custom Properties and the Cascade

A property only has an effect when it receives a valid value. Values can be keywords, colors, numbers, lengths, percentages or functions. A length usually needs a unit.

UnitRelative toCommon use
pxA CSS pixel reference unit; not necessarily one physical screen pixel.Fine borders and small fixed details.
remThe root element's font size.Consistent, scalable typography and spacing.
emThe computed font size of the element (for font-size, its parent).Spacing that scales with text.
%A context determined by the property, often a parent dimension.Flexible widths and proportional sizing.
vw / vhOne percent of the viewport width or height.Sizing related to the visible browser area.

Custom properties (CSS variables)

Custom properties store reusable values. Their names begin with two hyphens and they are read with var(). Defining common colors and spacing on :root makes them easier to update consistently.

CSS
:root {
  --brand-color: #174f78;
  --space-medium: 1rem;
}
.notice {
  color: var(--brand-color);
  padding: var(--space-medium);
}

How the cascade chooses a value

If several rules set the same property, the browser resolves the cascade by importance and origin, selector specificity, and then source order. A later rule wins only when earlier comparisons are tied. Inline styles commonly outrank normal stylesheet rules, but they are not an unconditional highest priority.

CSS
p { color: #333; }             /* element selector */
.notice { color: #174f78; }    /* class selector: more specific */
#warning { color: #a34b00; }   /* ID selector: more specific still */

Inheritance and debugging

Some properties, especially text-related properties such as color and font-family, are inherited. Many box properties, including margin, padding and border, do not inherit by default. The cascade determines an element's own value; inheritance can supply a value to a child when needed.

Debugging tip: browsers generally ignore an invalid declaration and continue parsing. Check property spelling, values, braces and semicolons when a style does not appear.

03. Colors and Backgrounds

CSS accepts named colors, hexadecimal notation, RGB and HSL. Alpha variants such as RGBA control the transparency of the color itself without making child text translucent. Use color for text and background-color for an element's background. Keep text/background contrast high enough for readability.

FormatExampleMeaning
Named colortomatoA predefined CSS color name.
HEX#FF6347Hexadecimal red, green and blue channels.
RGBrgb(255, 99, 71)Red, green and blue channel values.
HSLhsl(9, 100%, 64%)Hue, saturation and lightness.
RGBArgba(255, 99, 71, .55)RGB color with an alpha/transparency value.

Background properties

PropertyPurpose
background-colorFills an element with a solid color.
background-imagePlaces one or more images or gradients behind content.
background-repeatControls tiling: repeat, repeat-x, repeat-y or no-repeat.
background-positionSets where the image begins, such as center or right top.
background-sizecover fills the box; contain shows the whole image.
background-attachmentControls whether the background scrolls with the element or viewport.
CSS
.banner {
  background-color: #174f78; /* fallback color */
  background-image: linear-gradient(120deg, #174f78, #31765e);
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}

A gradient is an image generated by CSS. Repeated backgrounds can create patterns; gradients can provide color transitions without an image file.

04. Text and Fonts

Font properties set the typeface, size and weight. Text properties handle alignment and decoration. Relative sizes such as rem scale with the root font size, while unitless line-height scales naturally with text.

PropertyExampleEffect
font-familyGeorgia, serifTypeface with fallback families.
font-size1.1remText size.
font-weight700 or boldStroke weight.
text-aligncenterHorizontal text alignment.
line-height1.6Vertical room for each line of text.
text-decorationunderlineUnderline, overline or line-through.
text-transformuppercaseChanges visual letter case without changing source text.
CSS
.article {
  font-family: Georgia, serif;
  font-size: 1.1rem;
  line-height: 1.6;
  color: #24313d;
}
.article h2 { text-align: center; font-weight: 700; }
.article a { text-decoration: underline; }
.label { text-transform: uppercase; }

Borders and the Box Model

A border needs a style such as solid or dashed to be visible. The shorthand border: 3px solid #174f78; sets width, style and color together. One to four values can specify top, right, bottom and left in that order.

CSS
.solid { border: 3px solid #174f78; }
.dotted { border: 2px dotted #31765e; }
.dashed { border: 2px dashed #a34b00; }
.rounded { border: 1px solid #d7e0e5; border-radius: 12px; }

Box model: content, padding, border and margin

From the inside outward, an element consists of content, padding, border and margin. Padding is inside the border; margin separates the outside of one element from its neighbors.

With the default content-box sizing, a declared width applies only to the content; padding and border increase the rendered size. With border-box, the declared width includes content, padding and border. Margins remain outside either box. In normal block flow, vertical margins of adjacent blocks can collapse into one margin rather than add together.

SizingExample calculation
content-box (default)Declared width 300px + 20px padding on each side + 5px border on each side = 350px rendered width.
border-boxThe declared width includes the padding and borders, making layout calculations more predictable.
CSS
*, *::before, *::after {
  box-sizing: border-box;
}

05. CSS Positioning

The position property controls how an element is placed. Offsets such as top and right affect positioned elements according to their positioning context.

ValueHow it behaves
staticDefault position in normal document flow; offsets do not apply.
relativeRemains in flow and moves from its normal position; its original space remains.
absoluteLeaves normal flow and uses the nearest positioned ancestor as its containing block.
fixedLeaves normal flow and is positioned relative to the viewport.
stickyActs relative until a scroll threshold, then sticks within its scrolling container.
CSS
.card { position: relative; }
.card-badge {
  position: absolute;
  top: 12px;
  right: 12px;
}

Here the parent card has position: relative, so the absolutely positioned badge is anchored to the card instead of the page.

CSS3 and Modern CSS Features

CSS is developed as a collection of modules, such as Color, Selectors, Grid and Media Queries. “CSS3” is still commonly used in classrooms as a label for newer features, but there is no single all-encompassing CSS3 or CSS4 release; individual modules evolve on their own timelines.

Modern visual and layout features

  • border-radius creates rounded corners.
  • box-shadow adds depth around an element.
  • linear-gradient() creates a gradient background image.
  • transform changes an element's visual position, rotation or scale.
  • transition animates changes between property values.
  • Flexbox arranges items along one main direction, such as a row of navigation links.
  • Grid arranges items in rows and columns, such as a group of cards.
  • Media queries apply rules only when a condition, such as viewport width, is true.
CSS
.feature-list {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 14px;
}
@media (max-width: 600px) {
  .feature-list { grid-template-columns: 1fr; }
}
@media (prefers-reduced-motion: reduce) {
  .motion-demo, .motion-demo:hover {
    transition: none;
    transform: none;
  }
}

Flexible tracks such as minmax() and auto-fit can adapt between breakpoints. Choose breakpoints when the content needs them rather than targeting a particular phone model. Respecting reduced-motion preferences helps make interfaces more accessible.

Unit 3 Recap

  1. HTML supplies structure; CSS controls presentation.
  2. Selectors choose elements, declarations set values, and the cascade resolves competing rules.
  3. Inheritance, units, colors, text, borders and the box model shape how content is displayed.
  4. Positioning, Flexbox, Grid and media queries help arrange content across screen sizes.
  5. Modern CSS is modular and continues to evolve through individual specifications.

Before moving on: practise writing one rule for an element selector, one for a class, one for a hover state, and one responsive media query.
