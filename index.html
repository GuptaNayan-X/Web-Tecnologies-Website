Introduction to Web Technologies

Web Technologies is the study of how the World Wide Web actually works — the protocols, servers and addressing schemes that move information around, and the markup language, HTML, used to structure what people see in a browser. The Web is a system of interconnected pages reachable through the Internet's TCP/IP infrastructure: a browser (client) requests a resource over HTTP, a server returns it, and standards from the W3C keep every browser and server speaking the same language.
